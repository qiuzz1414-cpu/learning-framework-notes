# 成书流程（素材 → 教材）

> 成书模式时读本文件。目标：把用户给的全部素材，按 `assets/章模板.md` 的形式重构成自学教材。铁律：内容溯源素材，禁止编造。

## 0. 输入检查

素材形态可能是：整本书 PDF、讲义、题库、多份文件、零散笔记。先通读（大文件分批读），回答四个问题：

1. 这份材料的**全局主线**是什么？（用它填 01-全书骨架的主线与依赖图）
2. 有哪些可聚类的**题型/方法套路**？（它们决定各章 X.3/X.4）
3. 素材自带**习题和答案**吗？带年份/来源标注吗？（决定 X.5 与元数据表怎么填）
4. 多份素材之间**是否互相矛盾**？（有冲突先按 3.1 记下来，不要等到成文时才发现）

## 1. 全书规划（产出 01-全书骨架.md）

- 章节划分优先沿用素材自身结构；确需重组时向用户说明理由
- **先定死 N**（知识模块章数量），因为它决定速查总表与分支地图的章号（见 `assets/编写规范.md` 章节编号约定）；N 一经写入骨架，后续章节增减须回头改骨架，不能各章自行顺延
- 画依赖图：谁前置谁；跨章复用的对象/方法用旁注标出复用了什么
- 每章登记：覆盖的素材来源（文件名/页码）、样章候选（选套路最密、素材最厚的一章）

## 2. 逐章生成（产出 chapters/ch{X}-{章名}.md）

按 `assets/章模板.md` 的 X.0~X.6 顺序填充，每块的素材来源：

| 模板块 | 从素材取什么 |
|---|---|
| X.0 章导读 | 该章在素材中的前置与后续章节（前置基础/后续衔接据此写） |
| X.1 学习目标表 | 该章覆盖的方法与定理 |
| X.2 核心知识点 | 定义、定理、推导——作用先说，推导按编写规则显式展开 |
| X.3 套路速查表 | 从该章例题与习题**聚类**出的套路：识别信号取自题面特征 |
| X.4 套路七步 | 例题（典型例题）、解法（思路推演→形式化解答）、素材中出现的错误做法（易错点） |
| X.5 习题库 | 素材原题，保留 `[来源·时间]` 原标注；素材没给答案的题标"待补答案"；**多素材重复题合并为一个 ID，来源列用 `;` 列出全部来源**（见 `assets/编写规范.md` 题目标注与去重） |
| X.6 章末复盘 | 该章对象/方法在素材其他章的出现位置（跨章连接点） |

## 3. 溯源纪律

- 改写表述可以（这正是重构的价值）；编造事实、例题、数据、出处不行。
- 素材没有覆盖的块：写 `{素材未覆盖：需要什么}`，不要硬编；全部缺口在收尾时汇总成清单。
- 素材自带的题号、年份、来源**原样保留**进元数据表；没有的按 `ch{X}-ex-{nnn}` 重新编号。
- 引用素材某处内容时在文中标注来源，格式见 `assets/编写规范.md` 来源引用格式。

## 3.1 多素材冲突处置

多份素材对同一事实给出不同说法时，不静默取一个，按下列优先级处理并登记：

1. **优先级**：教材/正式出版物 > 课程讲义 > 个人笔记；同类素材取更新版本。
2. **核对可判定的**：能通过定义或推导确认哪个正确的，采用正确者，并在文中加 `[订正: 素材A 与 素材B 不一致，采用 B，理由 …]`。
3. **无法判定的**：两说并列保留，写 `[存疑: 素材A 作 X，素材B 作 Y]`，同时进缺口清单。
4. **禁止**：不得因冲突而删除任一素材中的题目；题目照收，答案冲突按上述规则在答案处标注。

## 3.2 缺口清单格式

收尾时缺口清单按下列表格式交给用户，不要用散文罗列：

| # | 位置 | 缺口类型 | 需要什么 | 涉及素材 | 影响 |
|---|---|---|---|---|---|
| 1 | ch3-sec-2 | 素材未覆盖 | 该节缺完整推导 | a.pdf | 读者无法自学该节 |

`缺口类型` 取值：`素材未覆盖` / `答案缺失` / `素材冲突存疑` / `页码不明`。

## 4. 大素材处理

- 一次读不完的素材：先读目录 + 抽样几节建全局地图，再逐章深读生成。
- **默认样章先行**：先完整生成一个样章（含全部 X.0~X.6）交用户确认；确认后按同一标准批量。
- 批量时逐章处理，不并行吞全书；每 3~5 章停下来汇报进度。
- 上下文放不下时，分章处理并把已确认的套路清单/元数据表记在 01-全书骨架.md 里作为跨章一致性锚点。

## 5. 收尾

- 生成倒数两章：`ch{N+1}-速查总表.md`（汇总各章 X.3 与核心公式）、`ch{N+2}-分支地图.md`；两者与 `chapters/` 平级，只引用既有编号，不新增 `-pat-` / `-ex-`
- 生成附录：`apx-a-反向索引.md`（由题目元数据表自动整理：按来源/时间倒序）、`apx-b-自检问题全集.md`（汇总全部自检问题）
- 向用户报告四样：文件清单、缺口清单（整表，含冲突存疑与答案缺失）、建议复核顺序（从样章开始）、多素材冲突的处置说明
