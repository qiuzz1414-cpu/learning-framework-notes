# 编写规范（填内容时统一遵守）

> 本规范约束所有章节的写作方式。写任何一章前先读一遍。

## 一、五条硬规则

1. **自检问题**一律用能力动词（"能否用 A 做 B"），禁止"是否理解 X"式提问。
2. **易错点**一律写成"反例 + 为什么错"，禁止"注意 XX"式空话。
3. **推导显式展开**：下列步骤不许跳——{按学科列出不许跳的步骤类型，如：换元后上下限同步修改、反证先写清反设、计数先说明计数对象是什么}。
4. **答案详略**：首次出现完整推导；复用允许写"沿用 {编号}"作为二刷索引。
5. **密度检验**：一刷读者应能无视全部导航元素线性读通；二刷和复习时导航元素才发力。

## 二、ID 与元数据规范

### 命名

| 对象 | 格式 | 示例 |
|---|---|---|
| 套路 | `ch{X}-pat-{n}` | ch4-pat-5 |
| 题目 | `ch{X}-ex-{nnn}` | ch4-ex-016 |
| 小节 | `ch{X}-sec-{n}` | ch4-sec-3 |

### 章节编号约定

知识模块章占 `ch1 … ch{N}`；N 在全书规划阶段定死，之后不再变动。其余区块按位置顺延：

| 区块 | 章号 | 说明 |
|---|---|---|
| 第 0 章 使用说明与预备 | `ch0` | 固定，不参与 N 计数 |
| 知识模块章 | `ch1 … ch{N}` | — |
| 公式与方法速查总表 | `ch{N+1}` | 即"倒数第 2 章" |
| 分支概念地图 | `ch{N+2}` | 即"倒数第 1 章" |
| 附录 A / B | 不参与章号 | 用 `apx-a` / `apx-b` 指代 |

**聚合章不新增套路与题目 ID**：`ch{N+1}` 只汇总引用 `ch1…ch{N}` 的 `ch{X}-pat-{n}`，`ch{N+2}` 同理。它们自己的小节仍按 `ch{N+1}-sec-{n}` 编号，但不得出现新的 `-pat-` / `-ex-` 编号，避免套路网出现无源节点。

### 题目元数据表

| 题号 | 章 | 套路 | 来源 | 时间 | 难度 |
|---|---|---|---|---|---|
| | | | | | |

#### 各列填法

- **套路**：填该题**主用套路**的 ID，必填。一题多套路时用 `,` 分隔，**首个为主用套路**，其余为关联套路。主用套路指题目主要考查的那一个，不是"也用到了"的那一个。
- **时间**：指题目对应的**考试/考核年份**（`2023` 或 `2023-06`），不是素材收录时间、不是文件修改时间。素材只给到年就只填年；素材明确不是考试题（如教材课后题）填 `—`；**素材没标时间就留空**，不填猜测值。
- **来源**：素材文件名；同一本书的不同版本要区分（如 `信号与系统(第三版).pdf`）。
- **难度**：只用于排序检索，取 `易` / `中` / `难`；不与 X.5 的分层混用。

### 题目标注与去重

**标注格式**：`ch{X}-ex-{nnn}　[来源·时间]`，全角空格分隔编号与方括号，方括号内用 `·` 分隔来源与时间。时间缺失写 `—`（如 `[a.pdf·—]`），**不得省略方括号或其中的分隔符**。

规范写法是整段标注放在行首、包在一对反引号内：

```markdown
- `ch1-ex-001　[a.pdf·2023]` 题面……
```

只把编号包进反引号（`` `ch1-ex-001`　[a.pdf·2023] ``）也算合法，检查器两种都识别；但同一本书内须统一，不要混用——混用会让 CID 排序和肉眼扫读都不一致。

**检查器不识别、会报 B05 的写法**：编号与标注被拆到两行，或编号后直接跟中文标点而无分隔。

**多素材重复题必须合并**：同一道题在多份素材中重复出现（题干实质相同，哪怕表述略有差异）时，**只保留一个题目 ID**，不得各编一个号。合并写法：

- 来源列写全部素材，用 `;` 分隔：`a.pdf; b.md`
- 题目标注取主来源（优先级最高者）：`ch1-ex-001　[a.pdf·2023]`
- 答案以完整解答那份为准；其余素材的答案若不同，按 3.1 冲突处置
- 去重判定：题目考查对象、条件、所求量三者一致即视为同题；仅数字不同视为同型不同题，不合并

### 冲突与订正标注位置

冲突标注**只写在答案块内**，位于 `**答案**：` 之后单独一行，不写在题干或 X.3 表中：

```markdown
**答案**：4
[订正: c.md 作 2，与 a.pdf/b.md 的 4 不一致；采用 4，理由：约分后为 x+2，代入得 4]
```

无法判定时写 `[存疑: a.pdf 作 X，b.md 作 Y]`，并在同一行末尾加 `→ 见缺口清单 #N`。

### 答案规约

答案不单独编号，**永远紧跟在题目同一小节之下**，保证"题—答案"不被拆散：

| 素材情形 | 写法 |
|---|---|
| 有答案且有解析 | 题目下写 `**答案**：` + 解析；解析详略按硬规则 4 |
| 有答案但只有结论 | `**答案**：{结论}`，另起一行 `{素材仅给结论，无解析}` |
| 无答案 | `**答案**：{待补}`，并登记进缺口清单 |
| 答案需复用他处 | 写"沿用 `{编号}`"，或 `答案见 ch{X}-ex-{nnn}` 反向引用 |

### 来源引用格式

正文与元数据引用素材统一写 `[来源: {文件名}#p{页码}]`。多份素材时文件名不可省略；页码用 **PDF 物理页码**，不是书内印刷页码；无法确定页码写 `#p?`。同一段连续引自同一处时只标一次。

### 缺口清单

缺口清单是成书模式的**强制交付物**，记录在 `01-全书骨架.md` 的「缺口清单」区块，逐条追加。

| # | 位置 | 缺口类型 | 需要什么 | 涉及素材 | 影响 |
|---|---|---|---|---|---|
| 1 | ch3-sec-2 | 素材未覆盖 | 该节缺完整推导 | a.pdf | 读者无法自学该节 |

`缺口类型` 只能取下列四种，不得自造：

| 取值 | 触发条件 |
|---|---|
| `素材未覆盖` | 该位置素材无对应内容，已写 `{素材未覆盖：…}` |
| `答案缺失` | 题目无答案，已写 `**答案**：{待补}` |
| `素材冲突存疑` | 多素材说法冲突且无法判定，已写 `[存疑: …]` |
| `页码不明` | 来源页码无法确定，已标 `#p?` |

`位置` 用 `ch{X}-sec-{n}` / `ch{X}-ex-{nnn}` / `ch{X}-pat-{n}` 定位，不用自然语言描述。

### 三张索引网（全部由元数据自动生成，不手写）

1. **依赖网**：章 → 章，决定学习顺序
2. **套路网**：套路 ↔ 题，双向可查。一题多套路时，**主用套路建主干链接，关联套路建旁路链接**（否则同一题会在套路表里出现多次、无法判断归属）
3. **时间网**：时间 → 题 → 套路，定位高频考点；时间为 `—` 或留空的题不进时间网，但仍进套路网

三者交叉后：任一题都能在"概念—题型—时间"三个维度归位。

## 三、每章生产顺序

```text
1  收集本章典型题目
2  聚类成套路清单
3  写 X.2 核心知识点
4  按 02-章模板.md 的 X.4 逐个写套路
5  配齐 X.5 习题与标注
6  写 X.6 复盘与自检
7  样章试读 → 修订模板 → 批量复制
```

## 四、全书推进路线

```text
Phase 0  写规范（本文件）+ 画全书依赖图
Phase 1  做一个样章，完整跑通全部模板
Phase 2  交给 1~2 个真实读者使用，记录哪里卡住、哪里跳过
Phase 3  按反馈修订模板，再批量生产其余章节
Phase 4  一轮使用后，用自检通过率反哺修订
```

最大的坑：开局把全书骨架搭满、每章平均用力——规范没经过一次真实使用就定型，返工成本极高。样章先行是唯一保险。

## 五、内容溯源（成书模式适用）

- 一切内容取自用户提供的素材；改写表述可以，编造事实、例题、数据、出处不行。
- 素材没有覆盖的块写 `{素材未覆盖：需要什么}`，不要硬编；全部缺口收尾时汇总成清单交用户决定。
- 素材自带的题号、年份、来源原样保留进元数据表；没有的按 `ch{X}-ex-{nnn}` 重新编号。
- 引用素材某处内容时标注来源（文件/页码），方便核对。
