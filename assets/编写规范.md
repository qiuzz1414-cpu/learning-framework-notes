# 编写规范（填内容时统一遵守）

> 本规范约束所有章节的写作方式。写任何一章前先读一遍。

## 一、五条硬规则

1. **自检问题**一律用能力动词（"能否用 A 做 B"），禁止"是否理解 X"式提问。
2. **易错点**一律写成"反例 + 为什么错"，禁止"注意 XX"式空话。
3. **推导显式展开**：下列步骤不许跳——{按学科列出不许跳的步骤类型，如：换元后上下限同步修改、反证先写清反设、计数先说明计数对象是什么}。
4. **答案详略**：首次出现完整推导；复用允许写"沿用 {编号}"作为二刷索引。
5. **密度检验**：一刷读者应能无视全部导航元素线性读通；二刷和复习时导航元素才发力。

## 二、ID 与元数据规范

### 命名

| 对象 | 格式 | 示例 |
|---|---|---|
| 套路 | `ch{X}-pat-{n}` | ch4-pat-5 |
| 题目 | `ch{X}-ex-{nnn}` | ch4-ex-016 |
| 小节 | `ch{X}-sec-{n}` | ch4-sec-3 |

### 题目元数据表

| 题号 | 章 | 套路 | 来源 | 时间 | 难度 |
|---|---|---|---|---|---|
| | | | | | |

### 三张索引网（全部由元数据自动生成，不手写）

1. **依赖网**：章 → 章，决定学习顺序
2. **套路网**：套路 ↔ 题，双向可查
3. **时间网**：时间 → 题 → 套路，定位高频考点

三者交叉后：任一题都能在"概念—题型—时间"三个维度归位。

## 三、每章生产顺序

```text
1  收集本章典型题目
2  聚类成套路清单
3  写 X.2 核心知识点
4  按 02-章模板.md 的 X.4 逐个写套路
5  配齐 X.5 习题与标注
6  写 X.6 复盘与自检
7  样章试读 → 修订模板 → 批量复制
```

## 四、全书推进路线

```text
Phase 0  写规范（本文件）+ 画全书依赖图
Phase 1  做一个样章，完整跑通全部模板
Phase 2  交给 1~2 个真实读者使用，记录哪里卡住、哪里跳过
Phase 3  按反馈修订模板，再批量生产其余章节
Phase 4  一轮使用后，用自检通过率反哺修订
```

最大的坑：开局把全书骨架搭满、每章平均用力——规范没经过一次真实使用就定型，返工成本极高。样章先行是唯一保险。

## 五、内容溯源（成书模式适用）

- 一切内容取自用户提供的素材；改写表述可以，编造事实、例题、数据、出处不行。
- 素材没有覆盖的块写 `{素材未覆盖：需要什么}`，不要硬编；全部缺口收尾时汇总成清单交用户决定。
- 素材自带的题号、年份、来源原样保留进元数据表；没有的按 `ch{X}-ex-{nnn}` 重新编号。
- 引用素材某处内容时标注来源（文件/页码），方便核对。
